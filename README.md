# 🍷 Wine Quality Analysis Dashboard (Excel)

## 📌 Project Overview

This project is an interactive Excel dashboard built using Microsoft Excel to analyze the Wine Quality dataset. The dashboard provides insights into wine quality, alcohol content, sugar levels, pH, and wine type using Pivot Tables, Pivot Charts, KPI Cards, and Slicers.

## 📊 Features

- 📈 KPI Cards
- 🍷 Wine Type Distribution
- 📊 Average Alcohol by Quality
- 🍩 Quality Category Distribution
- 📉 Average Quality by Sugar Category
- 📈 Average Quality by pH Category
- 📊 Average Alcohol by Density Category
- 🎛️ Interactive Slicers
- 📌 Dynamic Dashboard

---

## 📁 Dataset

- **Total Records:** 6,497
- **Red Wines:** 1,599
- **White Wines:** 4,898

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Tables
- Conditional Formatting
- Dashboard Design

---

## 📈 Key Insights

- 🍷 White wines represent nearly **75%** of the dataset.
- ⭐ Higher-quality wines generally contain higher alcohol percentages.
- 🍬 Sugar level influences wine quality.
- 🧪 Most wines fall within the normal pH range.
- 📊 Most wines belong to the **Average Quality** category.
